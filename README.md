# Ship Modal

WordPress向けのモーダル管理プラグインです。

## 主な機能

- HTML / リッチコンテンツと画像バナー
- 画像＋HTMLの複合レイアウト（画像位置：上・左・右）
- 複数ページのページャー（ページごとに画像＋HTML）
- 中央カード、下部バナー、右下ポップアップ、フルスクリーンの4デザイン
- 全ページ / トップページ / 投稿・固定ページ / ショートコードの表示範囲
- 自動表示 / ボタン表示、遅延秒数、開始・終了日時
- 毎回、セッションごと、1日1回、ユーザーごとに1回の表示頻度
- 表示回数・クリック数・クリック率の計測
- ESC、閉じるボタン、背景クリック、フォーカストラップ
- ページャーの前後移動、ドット移動、左右矢印キー
- GitHubのmainブランチからの自動アップデート（Plugin Update Checker）
